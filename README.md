# NOVA MARKAT

واجهة تجريبية عربية لمنصة تجارة إلكترونية جزائرية متعددة الأطراف، مبنية حاليًا بصفحة HTML وCSS وJavaScript مستقلة.

## تشغيل الواجهة التجريبية محليًا

من جذر المستودع شغّل:

```bash
python -m http.server 8080
```

ثم افتح `http://127.0.0.1:8080`.

- `index.html`: واجهة المتجر التجريبية.
- `style.css`: تنسيقات الواجهة.
- السلة والطلبات التجريبية محفوظة في `localStorage` على الجهاز والمتصفح الحالي.
- لا ترسل هذه النسخة طلبات فعلية إلى البائعين أو شركات التوصيل، ولا تحتوي على تسجيل دخول حقيقي أو قاعدة بيانات خلفية.

## النسخة الخلفية Django

يحتوي المستودع أيضًا على مشروع Django منفصل. لتشغيله محليًا:

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

تأكد من وجود ملف `.env.example` قبل نسخ الأمر، واضبط `SECRET_KEY` و`DEBUG` و`ALLOWED_HOSTS` حسب البيئة.

## النشر

### Netlify
انشر محتويات مجلد الواجهة الثابتة بحيث يكون `index.html` و`style.css` في جذر مجلد النشر نفسه. إذا كان الموقع منشورًا عبر رفع يدوي (Drop)، فلن تتزامن تغييرات GitHub تلقائيًا حتى تربط المستودع بالموقع أو تعيد نشر الملفات.

### Django على Render
ملف `render.yaml` يصف إعداد خدمة Django وقاعدة بيانات. راجع إعدادات الخدمة وملف البيئة قبل النشر. نشر الواجهة الثابتة على Netlify لا يشغّل Django تلقائيًا.

## حدود النسخة الحالية
هذه نسخة أولية للعرض والتجربة وليست متجرًا إنتاجيًا. قبل استقبال طلبات أو بيانات عملاء حقيقية، يجب ربط الواجهة بواجهة API وقاعدة بيانات، وتطبيق المصادقة والصلاحيات والتحقق من المخزون وحماية البيانات واختبارات شاملة.
